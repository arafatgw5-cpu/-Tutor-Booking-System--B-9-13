# 🎓 MediQueue – Tutor Booking System

🌐 Live Website: https://tutor-booking-system-psi.vercel.app

MediQueue is a modern tutor booking platform where students can easily find tutors, book learning sessions, and manage their schedules efficiently. The system helps eliminate manual scheduling conflicts and provides a smooth learning experience through an organized digital booking system.

---

## 🚀 Features

- 🔐 Secure Authentication with Email/Password & Google Login
- 🎓 Add, Update, and Delete Tutor Services
- 📅 Book Tutor Sessions with Automatic Slot Management
- 🔎 Search Tutors by Name with Dynamic Filtering
- 🌙 Fully Functional Dark & Light Theme Toggle
- 🔒 Protected Routes with JWT Authentication
- 📱 Fully Responsive Design for Mobile, Tablet, and Desktop
- ⚡ Real-time Toast Notifications for CRUD Operations
- 📊 Dynamic Tutor Availability & Session Booking System
- ❌ Prevents Overbooking with Automatic Slot Reduction

## ⚙️ Installation & Setup

### Clone the repositories

```bash
git clone your-client-repo-link
git clone your-server-repo-link
```

### Install dependencies

```bash
npm install
```

### Setup environment variables

Create a `.env.local` file for client:

```env
NEXT_PUBLIC_API_URL=your_server_url
NEXT_PUBLIC_FIREBASE_API_KEY=your_key
```

Create a `.env` file for server:

```env
PORT=5000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
```

---

## ▶️ Run Locally

### Client

```bash
npm run dev
```

### Server

```bash
nodemon index.js
```
